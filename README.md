# 🐑 Kashmir Online Sheeps & Farm Store (کشمیر شیپس آن لائن)

> **Kashmir's 1st Direct Farmer-to-Buyer Livestock Marketplace & Sheep Products E-Commerce Store.**
> Zero middleman (dalal) commissions • Direct WhatsApp / Call negotiation • Doorstep delivery across all 10 Kashmir districts.

🌐 **Live Website:** [https://sadiqk2.github.io/kashmir-sheeps/](https://sadiqk2.github.io/kashmir-sheeps/)

---

## 🌟 Key Features

### 1. 🐏 Live Sheep Mandi (خرید و فروخت)
- **Kashmir Merino (*Chhat / Mendha*):** Fine wool genetics, high growth rate, pasture-raised.
- **Bakarwali Mountain Breed:** Highland Himalayan sheep grazed on alpine pastures (Sonamarg, Gulmarg, Gurez).
- **Qurbani Ready Stock:** Verified teeth (*Doda / 2-teeth*, *Chog / 4-teeth*), certified horns, and veterinary vaccination records.
- **Flock Starters:** Merino ewes with lambs (*Dach / Bheed*).

### 2. 🛍️ Sheep Products & Byproducts Store
- **Organic Apple Orchard Manure (*Bheed Khad*):** Aged decomposed nitrogen & phosphorus fertilizer for apple trees (Shopian, Pulwama, Sopore) and saffron beds (Pampore).
- **Handspun Merino Wool Yarn:** 100% pure mountain wool yarn for traditional sweaters, caps, and pheran borders.
- **Traditional Handwoven Sheep Wool Blankets (*Loi / Chadar*):** Authentic warm natural wool blankets for sub-zero Kashmiri winters.
- **Himalayan Rock Salt Lick Blocks:** Pure mineral blocks with hanging ropes for livestock digestion.
- **Electric Sheep Shearing Clippers:** Professional 6-speed 680W machine clippers.

### 3. 🛒 Modern E-Commerce Experience
- **Interactive Shopping Cart Drawer:** Quantity increment/decrement, live subtotal, and shipping fee calculation.
- **Favorites & Wishlist (`❤️`):** One-tap bookmarking to compare prospective sheep.
- **Order Tracking Timeline:** Visual milestone tracking (*Order Placed → Vet Inspection → Kashmir Express Dispatch on NH44 → Doorstep Delivery*).
- **J&K Pincode Delivery Checker:** Instant validation for postal codes across Srinagar, Anantnag, Baramulla, etc.
- **Cash on Delivery (COD) & Instant UPI:** Flexible payment methods tailored to local buyers.

### 4. 🌐 Full Bilingual Support (English & Urdu RTL)
- **Instant Language Toggle:** One-click switcher between pure English and authentic Urdu (Right-to-Left / RTL with Noto Nastaliq Urdu typography).
- Kashmiri livestock terminology included: دودا (2 دانت), چوگ (4 دانت), مینڈھ / چھٹ (افزائشی نر), بھیڈ کھاد (باغات کی کھاد).

## 🚀 Local Development
1. Clone the repository:
   ```bash
   git clone https://github.com/sadiqk2/kashmir-sheeps.git
   cd kashmir-sheeps
   ```
2. Open `index.html` in your web browser:
   ```bash
   start index.html
   ```
